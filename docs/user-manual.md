# COS212 BST Tutor: Student Quick-Start Manual

Welcome! This guide is for students who are new to the COS212 BST Tutor. The app is a self-paced introduction to binary search trees (BSTs). You do not need to create an account.

## 1. Start the course

1. Open the app using the link provided by your lecturer or course.
2. Select **Get started**. If you have used the app before, the button may say **Continue where you left off**.
3. Read the lesson page from top to bottom. Look at the examples and diagrams, and try to explain each step to yourself.

There are four short lessons:

1. **Recognising a binary search tree** — tree vocabulary and the BST ordering rule.
2. **Searching and inserting** — how to follow a search path and add a value.
3. **Depth-first traversals** — pre-order, in-order, and post-order.
4. **Complexity and choosing a structure** — how tree shape affects search and when a BST or sorted array may be useful.

## 2. Explore and practise

The lesson page links to a few optional ways to practise. You can return to the lesson at any time using **Back to lesson** or the course menu.

### Try the BST visualiser

1. Choose **Try it in the visualiser**.
2. In **Insert values in order**, enter whole numbers separated by commas, such as `50, 30, 70, 20, 40`.
3. Submit the values with the button beside the field to build the tree. The order matters: the app inserts values in the order you enter them.
4. Choose an operation: insert, search, pre-order, in-order, or post-order traversal. Insert and search also need a value.
5. Select **Run operation**. Use **Back**, **Play/Pause**, and **Next** to follow the algorithm. **Speed** changes playback speed. **Reset** returns to the first step; **Reset demo** restores the original example tree.

Use **Start from an empty tree** if you want to build from scratch. The node count and tree height are shown below the controls. Inputs must be whole numbers from -9999 to 9999.

### Use the video and activity (optional)

- Select **Watch this lesson’s video** to see a related video. Video playback requires an internet connection and may depend on YouTube or network settings.
- Select the lesson activity to try a hands-on challenge. Depending on the lesson, you will practise tree parts and BST rules, search and insert, traversals, or tree shape and search cost. Follow the on-screen directions; sequence activities support clicking items into place as well as dragging them.

Videos and activities are optional. Completing them does not unlock the next lesson; passing the quick quiz does.

## 3. Take a lesson quick quiz

1. Choose **Take quick quiz** from the lesson page.
2. Select one answer. You can use **Hint** for help, or the read-aloud control to hear a question.
3. Choose **Submit answer** to see feedback. Once submitted, an answer cannot be changed; choose **Next question** to continue.
4. At the end, review your score and follow the next-step button.

You need **3 out of 4 correct (75%)** to pass and unlock the next lesson. If you do not pass, review the suggested concepts or lesson and select **Retry quiz**. Retrying has no penalty.

## 4. Complete the final mastery check

After you pass all four lesson quizzes, the **Final mastery check** becomes available. It has ten questions—one for each course learning outcome. Select and submit one answer per question, then review the result.

You need **8 out of 10 correct** to pass. If you do not pass, the results identify outcomes to review and link back to relevant lessons. You can retake the check without a penalty.

Passing unlocks your lecture-ready card and a downloadable wallpaper. The **Rewards** page also shows lesson banners earned by passing lesson quizzes.

## 5. Find navigation and settings

- Select the menu button in the header to open course navigation. It includes available lessons, the current lesson’s tools, and course tools. Locked lessons and tools become available as you progress.
- Open **Settings** inside the menu to turn **Sound** or **Reduce motion** on or off. Your preferences are saved in this browser.
- Your progress is saved in this browser, so it should be available when you return using the same browser and device. It is not tied to an account and may not transfer to another browser or device.
- **Start course over** clears lesson progress, quiz scores, and earned banners after you confirm. Your accessibility preferences are kept.

## Quick tips

- Work through the lessons in order; each lesson quiz unlocks the next one.
- You can revisit mastered lessons and repeat optional practice.
- In the visualiser, entering the same numbers in a different order can create a different tree.
- If saved progress is not available, check that you are using the same browser and device and that browser storage is enabled.
